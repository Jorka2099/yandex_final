# Планировщик задач (Task Scheduler)

# Описание проекта

Веб-сервер для управления задачами с поддержкой повторяющихся событий. Позволяет создавать, редактировать, удалять задачи и отмечать их выполнение. Поддерживает ежедневное и ежегодное повторение.

## Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

`pkg/api/` - HTTP обработчики всех эндпоинтов.
`pkg/db/` - работа с SQLite: подключение, запросы, транзакции.
`pkg/server/` - инициализация сервера,

### Инструкция по запуску локально

#### Требования
- Go 1.26 или выше

#### Установка и запуск

1. Установите зависимости:
```bash
go mod tidy
Запустите сервер:

bash
go run main.go
Сервер запустится на порту 7540. Откройте в браузере адрес: http://localhost:7540

Настройка порта
Для изменения порта используйте переменную окружения TODO_PORT:

bash
TODO_PORT=8080 go run main.go
Инструкция по запуску тестов
В файле tests/settings.go установите параметры:

FullNextDate = false

Search = false

Запустите все тесты:

bash
go test ./tests
Запуск отдельных тестов:

bash
go test -run ^TestAddTask$ ./tests
go test -run ^TestTasks$ ./tests
go test -run ^TestTask$ ./tests
go test -run ^TestEditTask$ ./tests
go test -run ^TestDone$ ./tests
go test -run ^TestDelTask$ ./tests
API Эндпоинты
Метод	Эндпоинт	Описание
POST	/api/task	Создать задачу
GET	/api/task?id={id}	Получить задачу по ID
PUT	/api/task	Обновить задачу
DELETE	/api/task?id={id}	Удалить задачу
GET	/api/tasks	Получить список задач
POST	/api/task/done?id={id}	Отметить задачу выполненной
GET	/api/nextdate?now={date}&date={date}&repeat={rule}	Вычислить следующую дату
POST /api/signin Авторизация

Формат задачи
json
{
    "id": "123",
    "date": "20260520",
    "title": "Название задачи",
    "comment": "Комментарий",
    "repeat": "d 3"
}
Правила повторения
d {n} - каждые n дней (n от 1 до 400)

y - ежегодно

Сборка и запуск через Docker
Docker не используется в этом проекте.
